# Дневники Агента (memory/)

Это директория для **ежедневных рабочих дневников** в формате `YYYY-MM-DD.md`.

## Ключевые правила

**Что писать:**
- Выполненные задачи и созданные файлы
- Принятые решения (особенно важные)
- Незавершённые дела и вопросы на будущее

**Структура файла:**
```
# YYYY-MM-DD

## Сессия N (время)
### Сделано
### Решения
### TODO на потом
```

Если несколько сессий за день — каждая получает свой заголовок.

## Назначение

Дневник помогает Агенту при возврате к проекту восстановить контекст и продолжить без потери информации.

## Что туда НЕ входит

- Долгосрочная информация о себе → `MEMORY.md`
- Справочники и инструкции → `knowledge/`
- Полный код или контент → сами файлы проекта

Дневник — **рабочий журнал, не отчёт**. Пишите кратко и телеграфно.
