### Решения

- `@fastify/static` подключается только в `NODE_ENV=production` чтобы не ломать тесты
- `bot.start()` только в production, после `app.listen()`
- `first_name` (snake_case) — стандарт Telegram WebApp API, не `firstName`
- `navigate()` вызывается только в `useEffect`, не во время рендера (React strict mode rule)
- deploy.sh исключает `node_modules`, `data`, `.git` из rsync
